# Othello-Game
Lets you play the game Othello against another human, a Greedy bot, or a Random bot – now with GUI!

## Running
Compile all files with javac *.java, then run OthelloGUI with java OthelloGUI.

## Playing the Game
The rules of Othello can be found [here](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english).

## Versus What?
This game lets you play against a random bot, a greedy bot, or another human!
